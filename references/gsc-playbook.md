# GSC 实操手册

目标：半天内从 Search Console 拿到能支撑诊断的五个数。没有 GSC 就别开始审计。

## 0. 权限

只读就够。让用户在自己的浏览器里登录（绝不代填账号密码），Agent 在同一会话里读页面。登录后确认左上角资源是 `sc-domain:目标域名` 还是 `https://域名/`，两者数据不通用。

## 1. 效果 → 查询数（最重要的意图信号）

默认「过去 28 天」，切到「查询数」。

读法：
- **前 20 个词的曝光加起来占总曝光多少？** 超过 70% 说明站被 Google 归到**一个**意图上。这是好事（主题集中），也说明其他页面没被认可。
- 这些词的**平均排名**集中在哪个区间？60–100 → 外链层；11–30 → 内容层；1–10 但曝光低 → 需求层。
- 有没有**品牌词**（`你的域名`）？没有品牌词 = 站外几乎没有提及。

实操：行数下拉选 500，然后用 `page.evaluate` 一次把表格全抓下来（GSC 会把全部行渲染进 DOM，不需要翻页）。

## 2. 效果 → 网页（决定治疗方案的那张表）

切到「网页」标签。这张表的每一行都是一个独立的诊断：

| 看到什么 | 结论 |
|---|---|
| 排名 60–100，曝光占比高 | 核心页卡在外链层 |
| 排名 7–20，单页曝光个位数 | 需求层挂了，选题没人搜 |
| 排名 30–50，曝光个位数到几十 | 快到了，推一把能进前 20 |
| 曝光 0 | 收录或 On-Page 问题 |

**最关键的交叉验证**：把「排名」和「曝光」两列一起看。
- 排名 7 / 曝光 18 → 词太小
- 排名 38 / 曝光 39 → 词还行，位置不够
这两个页面长得一样，但药方完全相反。

## 3. 索引报告

「网页索引编制」。已编入 / 未编入 + 原因列表。

**必须点进每一个原因看具体 URL。** 90% 是噪音（重定向、备用页、纯文本文件、Cloudflare 邮件混淆的 `/cdn-cgi/l/email-protection`）。

值得停下来的只有两条：
- **已发现 - 尚未编入索引**，且挂了超过两周 → Google 主动放弃抓取，页面被判低价值。这是**选题信号**。
- **已抓取 - 尚未编入索引** → 抓了但没收录，查内容质量/重复/canonical。

## 4. 链接数量

看 **外部链接的引用域数**，不是链接条数。

- 6 条链接来自 1 个域 = 1 个引用域 = 等于没有
- 内部链接数顺便看一眼，结合「最常链接到的网页」判断内链是否过度集中在某几页

GSC 不显示竞品外链。要看竞品得用 Ahrefs / Semrush / SimilarWeb，或者退而求其次搜 `"竞品域名" -site:竞品域名` 看谁提到过它。

## 5. 核心网页指标

显示「无数据」不等于有问题。**CrUX 只在流量足够时才采样**，新站没有数据是正常的，别去"修"它。

真要看性能，用 curl 测 TTFB + 浏览器测 DOMContentLoaded/Load，或者 Lighthouse。

## 6. 站点地图

提交状态「成功」只代表 Google 读到了这个文件，不代表里面的页面都被收录。

检查两件事：提交的 URL 数 vs 实际收录数；sitemap 里有没有 `<lastmod>`。

## 常见坑

| 坑 | 说明 |
|---|---|
| 用 `site:` 数收录 | Google 现在只回 10 条左右，必须用索引报告 |
| 28 天 vs 3 个月 | 新站用 28 天，老站用 3 个月看趋势 |
| 平均排名是所有词加权 | 一个站「平均排名 63」可能是 90 个 80 名的词 + 5 个 10 名的词，别当成"每个词都 63" |
| 搜索类型 | 默认「网页（文本）」，切到图片/视频会得到完全不同的数 |
