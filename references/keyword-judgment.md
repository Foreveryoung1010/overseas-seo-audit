# 选词判断：把"凭感觉选题"换成"过闸门"

## 为什么这个缺口最致命

审计过两个站，技术分 13/15 和 6/15，需求分都是 5/25。技术可以在一周内补齐，选题错了就是几十篇文章白写。

选错题的典型路径：

> 这个东西和我的产品相关 → 写一篇 → 发出去 → 4 周后没曝光 → 以为是自己写得不够好 → 再写一篇更长的

真正该问的是**在写之前**：这个词有没有人搜？搜的人是不是要我的东西？我能不能赢？

三个问题，三道闸门。**过不了第一道就不该写。**

---

## 闸门 1：需求（有没有人搜）

### 没有付费工具时，量从哪来

按可信度排序，四个免费源：

| 源 | 给什么 | 可信度 | 前提 |
|---|---|---|---|
| **Google 关键词规划师** | 月搜索量区间（如 100–1K） | 高 | 需要一个 Google Ads 账号，**不需要投放花钱** |
| **Bing 网站管理员工具 → 关键词研究** | Bing 的量 | 中（Bing 量约为 Google 的 1/5–1/10，看相对排序用） | 有 Bing 账号 |
| **Keyword Surfer（浏览器插件）** | 在 Google 搜索结果页直接显示每个建议词的估算量 | 中 | 装插件 |
| **Google 下拉建议** | 只证明"有人这么敲"，**不给量** | 低（有/无判断） | 无 |

再补一个不需要任何工具的：**看竞品有没有专门为这个词做页面**。有人花成本做，说明有量；没人做，大概率没有。

### 用 GSC 反推量级（最实用的方法）

页面已经有曝光但你不确定这个词大不大时，用这个：

```
相对量级 ≈ 28天曝光 ÷ 展示份额系数
```

展示份额系数（**粗估，只用于同站横向比较，不要当绝对值**）：

| 平均排名 | 系数 |
|---|---|
| 1–3 | 1.0 |
| 4–10 | 0.6 |
| 11–20 | 0.3 |
| 21–50 | 0.1 |
| 50 以上 | 0.03 |

**例**（真实数据）：

- `/ap203-ap214/`：39 曝光 ÷ 0.1（38.7 名）= **390 单位**
- `/why-is-my-stl-file-big/`：18 曝光 ÷ 0.6（7.3 名）= **30 单位**
- `/step-file-looks-wrong/`：11 曝光 ÷ 0.6（8.9 名）= **18 单位**

结论：AP203 那个词的需求量是"STL 文件太大"的 13 倍。**这个结论不需要任何付费工具，而且比工具更可信——因为是你自己的真实数据。**

用法：把自己所有页面的"曝光 ÷ 系数"算出来排个序，你就知道自己写过的 36 篇里，哪 3 篇选题是对的。

## 闸门 2：意图（搜的人要不要你的东西）

同一个词，意图不同，做出来的页面完全不同。

| 意图 | 词形特征 | 用户想要 | 你要给的 |
|---|---|---|---|
| 工具 | `xxx converter` / `free xxx` / `xxx online` | 立刻能用 | 工具本身，above the fold |
| 教程 | `how to xxx` / `xxx in 软件名` | 步骤 | 分步 + 截图 |
| 问答 | `can xxx` / `does xxx support` / `why xxx` | 一个明确答案 | 首段 100 字内回答 |
| 排障 | `xxx error` / `not working` / `too big` | 原因 + 解法 | 病因表 + 修复步骤 |
| 对比 | `a vs b` | 决策依据 | 一张对照表 |
| 购买 | `best xxx` / `xxx alternative` | 选哪个 | 评测 + 推荐 |

**判断方法**：把词丢进 Google，看前 10 都是什么形态。全是工具页 → 工具意图；全是论坛问答 → 问答意图；混合 → 意图模糊，慎做。

**错配的典型**：用一篇文章去打一个工具词（用户要的是能点的按钮，不是 3000 字）。反过来，用一个工具页去打一个教程词（用户想看步骤，不想填表单）。

## 闸门 3：竞争（你赢得了一吗）

只看一件事：**前 10 的构成**。

| 前 10 | 判断 | 新站预期 |
|---|---|---|
| 论坛帖 / Reddit / YouTube / GitHub issue | ✅ 最好打 | 2–4 周进前 20 |
| 官方文档 + 社区帖，无内容页 | ✅ 最好打 | 2–4 周，而且你就是唯一内容页 |
| 1–2 篇老博客/小站专门页 | ⚠️ 可以打 | 4–8 周，内容要更好 |
| 全是多年老工具站（且域名就是关键词） | ❌ 打不动 | 6–12 个月，先排 30–50 名 |
| 全是电商/大平台 | ❌ 不该打 | 换词 |

**这一步永远不能交给"竞争度分数"。** 同一个分数下，论坛型 SERP 和工具型 SERP 的难度差十倍。

已实测的两个极端：

- `does cura support step files` → 10/10 是官方文档、社区帖、GitHub issue，**没有一篇内容页**
- `stp file viewer online` → 10/10 是专门做的工具站

在工具里这两个可能都是"中等难度"。

## 选题 brief：四格缺一不可

写之前填完这张表，填不满就不写。

```
目标词：
前 10 构成：       （逐个记下来源和性质，不是"竞争激烈"这种废话）
需求量级：         （关键词规划师的区间，或 GSC 反推值）
我的差异化：       （只有我有的：实测数据 / 自研工具 / 真实案例 / 独家文件）
```

第四格是**能不能长期活下来**的关键。写不出差异化，就只能在"比别人长"上卷，而长度是最容易被 AI 抹平的东西。

## 校准训练：让判断力长出来

### 方法一：预登记

每周挑 5 个候选词，先写下预测再动手：

| 词 | 预测（4 周后） | 实际 | 差在哪 |
|---|---|---|---|
| A | 进前 20，月曝光 100+ | | |
| B | 进前 30，月曝光 30 | | |

4 周后对答案。**连续对 4 周，你对"能不能赢"的判断会准得吓人**，因为你有反馈了。大多数人的问题不是笨，是从来没对自己的判断负过责。

### 方法二：用历史数据反推

把站上已有页面的「曝光 ÷ 系数」算一遍，按降序排。你会看到：

- 哪几篇选题是对的（量大）
- 哪几篇是自嗨（排名不低但量极小）

这一步做完，你对"什么词有量"就有直觉了——而且是用自己的钱和时间换来的直觉。

### 方法三：抄结构，不抄内容

看竞品 sitemap 的 URL 结构，看它把哪些词拆成了独立页面。**它拆了页 = 它验证过这个词有量。** 这是最便宜的需求验证。

## 反模式清单

| 反模式 | 为什么错 |
|---|---|
| 「这跟我的产品有关，写一篇」 | 相关性 ≠ 需求 |
| 「这个词竞争低，做它」 | 竞争低往往因为没人搜 |
| 「先写 30 篇再优化」 | 无法归因，也不知道哪篇对 |
| 「同行都在写，我也写」 | 同行可能也在亏 |
| 「这个词搜的人少但精准」 | 少到 20 次/月就不叫精准，叫没有 |
| 「AI 能写，先铺量」 | 铺的是没人搜的量 |

---

## 一句话总结

**选题不是创意工作，是数据工作。** 三道闸门全部通过才写，任何一道不过就换词——换词的成本是 1 小时，写错一篇的成本是 1 天加工信心的损耗。
