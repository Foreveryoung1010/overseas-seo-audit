# overseas-seo-audit

出海网站 SEO 全站审计技能 —— 给 AI agent 用的一套判断流程。

不是"SEO 检查清单"，是**归因方法**：先判断一个站卡在哪一层，再给那一层的药。

---

## 它解决什么问题

大多数人做 SEO 失败，不是不会优化，是**改错了地方**：

- 排在 60–100 名，却一直在加内容（那是外链层的问题）
- 排到第 7 名，还在高兴（先看曝光：第 7 名一个月 18 次曝光 = 这个词没人搜）
- 没流量，先怀疑收录（可能收录 40/41，照样只有 2 次点击）

这套技能的核心是先做一个判断，再动手。

## 核心模型：四层

| 层 | 决定什么 | 缺失时的症状 | 修复周期 |
|---|---|---|---|
| **0. 需求** | 有没有人搜这个词 | 排到第 7 名，一个月 18 次曝光 | 换选题，2–4 周 |
| **1. On-Page** | 能不能进"待排名范围" | 搜核心词完全找不到自己 | 1–2 周 |
| **2. 外链** | 能不能进前 10 | 稳定卡在 60–90 名 | 3–6 个月 |
| **3. 体验/点击** | 最终停在第几位 | 有曝光没点击 | 持续 |

前三层来自「On-Page 决定范围 / 外链决定前 10 / 体验决定最终位置」这个经典拆法。**第 0 层是实战补的**，因为最容易死的恰恰是最前面那层。

用 GSC 的「网页」标签页就能定位：

| 平均排名 | 归因 |
|---|---|
| 60–100 | 外链层 |
| 11–30 | 差临门一脚 |
| 1–10 但曝光个位数 | **需求层** |
| 完全没有曝光 | 收录 / On-Page |

## 安装

技能是纯 Markdown，没有依赖。放进你的 agent 技能目录即可：

```bash
# OpenCode / Claude Code 类工具
git clone https://github.com/Foreveryoung1010/overseas-seo-audit.git \
  ~/.config/opencode/skills/overseas-seo-audit
```

Windows：

```powershell
git clone https://github.com/Foreveryoung1010/overseas-seo-audit.git "$env:USERPROFILE\.config\opencode\skills\overseas-seo-audit"
```

装好后 agent 会在遇到"审计网站 / 为什么没流量 / 排名上不去 / 这个词值不值得做 / AdSense 能不能过"时自动加载。

## 脚本用法

```bash
# GSC → 效果 → 网页 → 导出 CSV
node scripts/gsc-demand-rank.mjs Pages.csv
```

输出按「曝光 ÷ 排名系数」降序，直接标出哪些页面该修、哪些该停、哪些该弃。
系数是经验值，**只用于同站横向比较，不等于月搜索量**。

## 它的边界

这个技能故意把不知道的东西写清楚，因为审计的价值一半在这里：

- **没有 Ahrefs / Semrush 就拿不到真实搜索量。** 所有"能不能打"的判断依据是 SERP 前 10 的构成 + 站内回测排序，不是绝对量。
- **没有 GSC 就只能靠外部信号推断**，报告会明确标注置信度低。
- **`site:` 不能用来数收录量。** Google 现在只回 10 条左右，收录只看 GSC 索引报告。
- **不判断"这条外链值多少钱"。** GSC 只给引用域数量，给不了权重。

## 它从哪来

一份公开的 SEO 直播分享（三小时，18 条要点）+ 两次真实站点审计的修正。

两次审计各暴露了一个原模型没覆盖的问题：

| 踩的坑 | 补进技能的东西 |
|---|---|
| 排 7 名但月曝光 18 次 | 加了「需求层」 |
| 用 `site:` 数收录，误判 75% 没收录 | 铁律：收录只看 GSC |
| 6 条外链其实来自同一个域 | 铁律：只看引用域 |
| 全站软 404（不存在的 URL 返 200 + 首页） | 第 2 步加软 404 探测 |
| 品牌名重名，品牌词永远搜不到自己 | 常见误判加一条 |
