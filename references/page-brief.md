# 单页写作模板

一个页面只回答一个问题。写之前先把标题定死，标题定不下来说明意图没想清。

## 结构

```
title        ≤60 字符，目标词前置
H1           与 title 同义但不同字，含目标词
第一段       100 字内直接给答案（AI 摘要和用户都只读这段）
─────────────
H2  答案的细节
H2  怎么操作（步骤 / 代码 / 截图）
H2  常见失败原因
H2  和相邻概念的区别（导流到关联页）
─────────────
FAQ          3–5 条真实问法（注意：不产生富摘要了）
内链         1 条指向 L1/L2，锚文本用该页的核心词
```

## 首段规则

**先给结论，再给理由。** 用户从搜索结果点进来只想知道"能不能 / 要多久 / 多少钱 / 对不对"。

- ✅ "Cura 不能直接打开 STEP 文件。它只吃网格格式，STEP 是实体格式。要么装 STEP/IGES Import 插件，要么先转成 STL。"
- ❌ "在 3D 打印的漫长历史中，文件格式一直是工程师们讨论的话题……"

## 关键词怎么放（替代"密度 3–5%"）

不数百分比。按位置放：

| 位置 | 要求 |
|---|---|
| `title` | 目标词在前 30 字符内 |
| `H1` | 含目标词，但不与 title 完全重复 |
| 首段 | 目标词出现 1 次，自然句子里 |
| 至少 1 个 H2 | 含目标词或其变体 |
| 内链锚文本 | 用目标页的核心词 |
| 图片 alt | 描述性，含目标词 |
| `description` | 不是排名因素，但影响点击率，写成人话 + 一个具体数字 |

语义覆盖比重复更重要：讲 `STEP to STL` 就自然会出现 `tessellation`、`B-rep`、`triangle count`、`slicer`、`mm`、`AP203` 这些相关词。这是算法真正在看的。

## 字数怎么定（替代"800–1000 词"）

不是目标，是结果。

1. 打开该词的前 10 名，量出**回答完这个问题需要多少内容**
2. 你的页面 ≥ 这个长度，且**多一样别人没有的东西**

"多出来的那一样"只能是这四种之一：

- 实测数据（跑出来的数字、耗时、文件大小）
- 可下载的东西（样例文件、模板、脚本）
- 一个能直接用的工具
- 真实的失败案例和排错步骤

没有这四样之一，写多长都是可替代内容。

## 自检清单

- [ ] 标题里能不能看出这页解决什么问题（不看正文也能）
- [ ] 首段 100 字内有没有给出答案
- [ ] 有没有一个数字是这页独有的
- [ ] 有没有一条内链指向上一级
- [ ] 内链锚文本是不是具体词（不是"这里""了解更多"）
- [ ] 有没有跟站内其他页面抢同一个意图
- [ ] 移动端首屏能不能看到结论（不是一堆导航）
- [ ] 有没有加 FAQPage（加了也没富摘要，如果只是为 SEO 可以删）

## 反面样本（真实踩过的）

一篇 5000 词、有实测数字、核心词在 title/H1/首段全齐的文章，排到 7.3 名，28 天 18 次曝光。

**On-Page 满分，需求零分。** 写作模板解决不了选题问题——模板只能保证"排得进去"，保证不了"有人搜"。
