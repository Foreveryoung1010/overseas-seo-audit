# 外链：抄竞品的作业

新站拿第一批外链只有一条稳的路：**去别人已经在提问的地方给答案，并留下链接。** 买链接、PBN、批量目录在 2026 年会直接拖垮整站，别碰。

## 1. 先摸清竞品的链接从哪来

有 Ahrefs / Semrush：直接拉竞品的 Referring Domains，按 DR 升序排（先抄低权重的，好抄且够用）。

没有工具时的替代办法：

1. Google 搜 `"竞品域名" -site:竞品域名` —— 看谁提到过它
2. 搜 `competitor名 + alternative` / `competitor名 + review` —— 目录站和评测站通常在这类查询里
3. 看竞品官网的 "Featured on / As seen in" 区块
4. 看它出现在哪些 GitHub awesome-list、知乎/Reddit 帖、行业清单

## 2. 分类，只抄能抄的

| 类型 | 能不能抄 | 怎么做 |
|---|---|---|
| 论坛/社区回答 | ✅ 最有效 | 真回答问题，链接放最后 |
| 工具目录 | ✅ 一次性 | 每个目录提交一次，别重复 |
| 行业清单（awesome-list） | ✅ 持久 | 先做点开源的东西再提交 |
| 教程/博客里的引用 | ⚠️ 靠关系 | 给作者提供独家数据，请他引用 |
| 客座文章 | ⚠️ 慢 | 一个月 1–2 篇够了 |
| 付费链接 / PBN / 批量目录 | ❌ | 会连累整站 |

## 3. 论坛打法（80% 的产出在这里）

**渠道清单（按赛道找）：**

- 综合：Reddit 对应 subreddit、Hacker News（Show HN）、Stack Exchange 对应站
- 垂直：该领域 2–3 个官方论坛（软件官方的社区往往权重最高）
- 问答：Quora、GrabCAD Questions 这类垂直问答站

**执行规则：**

1. 按**最新**排序找没被回答的问题，别去回三年前的老帖
2. 答案必须能独立成立——把链接删掉，这段回答仍然有用
3. 针对那个提问者的具体情况，不要复制粘贴同一段
4. 一个帖一条链接，不刷
5. 每周 5–10 条，坚持 4 周

**判断有没有效**：GSC「链接数量」里出现的引用域数量。**不看链接条数。**

## 4. 目录提交清单（通用型）

Product Hunt（只发一次，选周二到周四）、AlternativeTo、SaaSHub、Slant、Toolify、还有该赛道的垂直目录。

每个目录只提交一次，描述不要一字不差地复制——重复描述会被当成垃圾提交。

## 5. 最高性价比的一招：开源一个小组件

把站内某个能力抽出来做成 CLI / npm 包 / GitHub Action，README 里链回主站。

- 链接是 dofollow 且长期有效
- 能进 awesome-list（一个 list 一条，且会被其他项目引用）
- 开发者会真的点进来

比发 50 条论坛帖更持久。

## 6. 什么算"有效外链"

| 情况 | 算不算 |
|---|---|
| HTML 源码里的 `<a href>` | ✅ |
| `rel="nofollow" / "ugc" / "sponsored"` | ❌ 不算权重票，但可能带点击 |
| JS 动态渲染出来的链接 | ❌ 大概率不计 |
| 302 跳转的链接 | ❌ 不传权重 |
| 同一个域的第 2 条以后 | ❌ 只算 1 个引用域 |

## 7. 4 周目标

| 周 | 动作 | 预期新增引用域 |
|---|---|---|
| 1 | 竞品外链摸底 + 目录提交 5 个 | 3–5 |
| 2 | 论坛回答 10 条 | 3–5 |
| 3 | 论坛回答 10 条 + 开源组件发版 | 4–8 |
| 4 | 论坛回答 10 条 + awesome-list 提交 | 3–6 |

合计 15–25 个引用域。这个量级对「从 78 名挪到 30 名」是有意义的，对「进前 10」还不够——那是 6 个月的活。

## 8. 红线

- ❌ 买流量凑 AdSense 门槛 → 账号级封禁，一次就废
- ❌ 买链接 / 链接农场 / PBN
- ❌ 一个域短时间内塞几十条链接
- ❌ 自动化群发论坛（会被识别并封号，反而丢掉已有的真实链接）
